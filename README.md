# The Last Light: A Dream Escape

## About the Game

*The Last Light: A Dream Escape* is a side-scrolling platform game created using Microsoft MakeCode Arcade.

The player controls a girl trapped in a dark dream. She needs to collect five stars, avoid ghosts, and reach the exit door to escape.

The game uses darkness to represent fear and light to represent hope.

## Play the Game

**Game Link:**

https://arcade.makecode.com/S54765-08857-17528-62373

Open the link to play the game online.

## How to Play

- **Left Arrow:** Move left
- **Right Arrow:** Move right
- **A Button:** Jump

## Game Rules

- The player starts with three lives.
- Collect five stars to complete the objective.
- Touching a ghost removes one life.
- After taking damage, the player has a short protection period.
- Reach the exit door after collecting five stars to win.
- The game ends if all three lives are lost.
- If the player reaches the exit without five stars, a reminder appears.

## Main Features

- Side-scrolling platform gameplay
- Character movement and jumping
- Gravity and Tilemap platforms
- Camera following the player
- Five collectible stars
- Ghost enemies and collision detection
- Score and life systems
- Win and lose conditions
- Background music and sound effects

## How to Run

**Option 1: Play Online**

1. Open the game link above.
2. Start the game.
3. Use the arrow keys and A button to control the character.

**Option 2: Open in MakeCode Arcade**

1. Visit https://arcade.makecode.com/
2. Open the MakeCode Arcade editor.
3. Click **Import** and select a compatible exported project file.
4. Run the game using the simulator.
